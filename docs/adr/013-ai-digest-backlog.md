# ADR-013: AI Digest Marked as Unscheduled Backlog

**Status:** Accepted
**Date:** 2026-07-01

## Context

"AI Digest" was listed as a Core Module in the original vision but never
appeared anywhere in the Phase 0–7 roadmap, silently implying scope the plan
never actually accounted for.

## Decision

AI Digest is explicitly marked as **post-v1 backlog** — not scheduled in any
current phase. It remains a stated goal, to be revisited only after Phases
0–7 are functional.

## Consequences

- Prevents scope creep into the current roadmap.
- Preserves the idea for later without pretending it's currently planned.
